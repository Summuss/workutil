# 04: 书签页提示条改为浮层

**What to build:** 书签页的 `notice`(「打开了 5 个,跳过 2 个」及其明细列表)和 `error` 现在是插在内容流里的普通元素,出现时把下面所有东西推下去 —— 而「跳过了哪几条」的明细可能有好几行,推挤幅度不小。

改成**绝对定位浮在滚动区顶部**,不占布局高度。关闭按钮已有,保留。

只改书签页。其他页的错误提示都是单行文字、位置固定,不会造成可见的跳动,不为一致性去动它们。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `notice` 与 `error` 移出内容流,浮在滚动区顶部,不占布局高度
- [ ] 一键打开一组、其中有失效项时,列表**不发生任何位移**
- [ ] 明细列表很长时浮层自身可滚或截断,不盖住整个列表
- [ ] 关闭按钮仍然可用,关闭后不留空白
- [ ] 浮层在滚动内容时保持在顶部,不跟着列表滚走
- [ ] 三种 notice 类型(success / warning / info)的配色保持现状
- [ ] 其他页面的错误提示不动
- [ ] `make check` 通过
