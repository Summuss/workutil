# 02: 前端图钉按钮与置顶区

**What to build:** 图钉按钮在**折叠态和展开态都有**:折叠态放在右侧展开箭头的左边,展开态放进头部工具栏(转 Todo / 编辑 / 删除 那一排)。已置顶的图钉高亮,再点一次取消。图钉图标新增到 `shared/icons.tsx`,沿用现有 feather 描边风格。

置顶区和普通列表之间要有一条分隔(细线 + 小标题)。没有它就分不清一条 memo 是新写的还是被钉住的。置顶区为空时**整个分隔和标题都不渲染**,不留一块空标题。

搜索状态下不显示置顶区(顺序由服务端定,前端只要不自作主张分段),但图钉按钮本身还在 —— 可以在搜到之后顺手钉住。

`SingleMemoPage`(`/memo/:id`)放同一个图钉按钮。
