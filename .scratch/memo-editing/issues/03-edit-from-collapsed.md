# 03: 折叠态直接进编辑

**What to build:** `MemoItem` 折叠态的图标区加一个编辑按钮,点它 = 展开 + 直接进入编辑态,光标落在末尾。

折叠态图标区现在是「置顶 + 展开」两个,加进编辑变三个。用 `shared/icons.tsx` 里已有的 `EditIcon`,和展开态头部那个一致。

**保存后留在展开态**,和从展开态进入编辑的行为一致。自动折叠回去会让人看不到自己刚存了什么,而 `Esc` 和折叠箭头都在手边。

**这条不违反「编辑由按钮进入,而不是点正文」那条铁律** —— 进编辑的仍然是一个按钮。那条铁律防的是「拖选正文时误入编辑态」,和这里无关。

**Blocked by:** 无
