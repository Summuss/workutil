# 03: 截止日期

**What to build:** 可选的 `due_date`,以及它在列表里的显示。

**只到日,不带时分。** 带上时间就要处理时区和「几点算逾期」,而自用待办的粒度从来不是小时。

**它不参与排序。** 大多数待办没有 deadline,拿它当排序键的结果是绝大多数项挤在「没有日期」的一坨里 —— 那等于把 02 的手工排序作废。它**只负责显示**,分三档:

| 状态 | 显示 |
| --- | --- |
| 逾期 | 红 |
| 今天到期 | 橙 |
| 未来 | 灰 |
| 没有日期 | 什么都不显示 |

三档是有行动含义的最小划分:红 = 已经晚了,橙 = 今天必须动,灰 = 还没到该管的时候。

**不做提醒 / 通知** —— 那需要一个常驻进程,超出本工具的形态(design.md §1)。
