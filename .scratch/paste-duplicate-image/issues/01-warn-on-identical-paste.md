# 01: 粘到和上一张一模一样的图时先问一句

**Status:** ready-for-agent

**Blocked by:** 无

**What to build:** 在 `shared/` 里记住「最近一次成功粘贴的图片指纹」,重复时拦一下。

- 指纹用 `crypto.subtle.digest("SHA-256", bytes)`,**前端算,不上传**。`crypto.subtle` 在 `http://127.0.0.1` 上算 secure context,可用;拿不到时(异常/不可用)**静默跳过这道检查**,绝不能因此挡住粘贴。
- 记一个值就够 —— 最近一次**成功粘进去**的那张。不分 case、不分页面、不持久化(会话级即可)。被用户取消掉的那次不更新它。
- 命中时 `window.confirm` 一句:说清楚「这张和上一张一模一样,截图可能还没写进剪贴板」,给「还是加进去 / 取消」两个出口。取消就什么都不做。
- **两处接同一条规则**:
  - evidence(`CaseBlocks.handleImages`)—— 拦在 `addImageBlock` 之前,别让它落盘再删;
  - memo(`useImageAttachments.insertImages`)—— 拦在插占位符之前。
- 一次粘多张时,只和上一张比第一张,别在一次粘贴内部互相比(一次选了两张不同的图是正常的)。

**不做**:感知哈希、和整个 case / 整份 evidence 比对、持久化指纹、自动去重。理由都在 spec。

- [ ] 连着粘同一张截图两次 → 第二次被问一句;选「取消」则什么都没发生(不落盘、不多出 Block、列表不滚动)
- [ ] 选「还是加进去」→ 正常建 Block,行为和以前一样
- [ ] 粘两张**不同**的截图 → 一次都不问
- [ ] 取消之后再粘同一张 → **仍然会问**(被取消的那次不算「成功粘贴」)
- [ ] memo 里连粘同一张两次,同样被问一句
- [ ] 在 evidence 粘了一张,切到 memo 粘同一张 → 会问(范围不分页面,这是有意的)
- [ ] 从 Excel 复制一段区域粘贴 → 仍然走表格那条路,这道检查完全不参与
- [ ] `crypto.subtle` 不可用时,粘贴一切照常,只是不再问
- [ ] `pnpm build` / `tsc` 通过
