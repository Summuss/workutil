# 03: evidence 详情页的 memo 侧栏

**Status:** ready-for-agent

**Blocked by:** 02

**What to build:** evidence 详情页右侧一个可收放的**只读** memo 侧栏。取舍与理由见 [ADR-0013](../../../docs/adr/0013-memo-panel-lives-inside-evidence.md),这里只写形状。

**布局**

- 侧栏与 `PageLayout` **并排**:路由元素外面包一层 flex-row,`PageLayout` 自己那套 `flex-1 min-h-0` 一行不动。
- **占满整个内容区高度** —— 标题行、用例标签栏、block 列表、粘贴框一起变窄。不是只占 block 列表那一段(侧栏顶部的搜索框会悬在页面中段)。
- **挤压**,不是覆盖、更不是推开。推开会带来横向滚动,[ADR-0007](../../../docs/adr/0007-fixed-viewport-shell.md) 明令禁止。
- 固定 `360px`,**不可拖拽**。
- ⚠️ 侧栏自己内部要滚的那一块**必须显式写 `min-h-0`** —— design.md §3.4 把这条列为这套布局唯一的常驻陷阱,漏一个症状看起来像「这次改动没生效」。

**内容(只读)**

- 顶部一个搜索框,复用 memo 现成的 `listMemos(query)`,不加新接口。
- 结果列表:命中片段的呈现照 memo 页的既有做法(`HighlightText`),别新写一套。
- 点一条展开看正文,用 `shared/Markdown` 渲染(图片、灯箱因此自动就有了)。
- **文字要能拖选复制** —— 这是「拿一段字」那半的全部实现方式。所以正文外层不要挂任何 `onClick`,别重蹈 memo 那个「拖选被当成点击」的覆辙(design.md §6 F1 记着它退回来过一次)。
- **没有**编辑、删除、置顶、新建,**没有**「插入到当前用例」。

**开合**

- 快捷键 `Ctrl+M`,**只认 `event.ctrlKey`,不认 `event.metaKey`**。macOS 上 `Cmd+M` 是系统级的「最小化窗口」,抢不过来。这是全项目第一个破掉「两个一起认」那条惯例的手势,**代码里要写一行注释说明为什么破例**,否则下一个人会以为是漏写了一半。
- 也要有一颗看得见的按钮,不能只有快捷键。
- 开合状态记 localStorage(照抄 `MemoList` / `i18n` 的 try/catch 写法),宽度不记。
- 侧栏开着时,`Ctrl+M` 关掉;焦点在侧栏搜索框里时 `Esc` 先清搜索、再按一次关侧栏(别让 `Esc` 一下子就关掉一个刚搜到一半的东西)。

**只在 evidence 详情页。** 不铺到 Todo、书签、memo 页。

- [ ] `Ctrl+M` 开合侧栏;macOS 上按 `Cmd+M` 是最小化窗口,不误触侧栏
- [ ] 侧栏开着时 evidence 内容区变窄,**页面不出现横向滚动条**,用例标签栏照常横滚
- [ ] 侧栏里搜一条 memo、展开、拖选一段文字复制 → 选区不会因为松手而消失
- [ ] 复制到的内容能直接粘进下面的粘贴框
- [ ] 侧栏里的 memo 正文里的图片能点开看灯箱
- [ ] 开着侧栏切换用例、粘截图、编辑文字块,全部照常
- [ ] 关掉侧栏,evidence 恢复原来的宽度,**当前用例和滚动位置没变**
- [ ] 刷新页面,侧栏的开合状态和上次一样
- [ ] Todo / 书签 / memo 页上按 `Ctrl+M` 什么都不发生
- [ ] 窄窗口(约 1100px)下开侧栏,布局不塌、不横滚
