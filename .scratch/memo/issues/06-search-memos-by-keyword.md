# 06: 按关键词搜索 Memo

**What to build:** 让几个月前记下的东西能被找回来 —— 这是记事本失败的地方,也是本功能存在的主要理由。

搜索结果必须显示**命中的那段文字**,而不只是正文开头。因为 Memo 没有标题、列表显示的是首行,而首行往往不包含你搜的词:搜 `token` 命中的那条,首行可能是「今天调登录」,匹配其实发生在第五行 —— 只显示首行,使用者完全看不出这条为什么会出现在结果里。

实现使用**子串匹配,不使用 FTS5**(见 ADR-0002)。下面列出的中日文用例是这条决定的**护栏**:换成 FTS5 后它们会立刻失败,而只有英文用例的测试套件察觉不到这个问题。

片段提取是一个**纯函数**(输入正文与查询词,输出片段),不接触数据库和文件系统。它是本模块唯一一个低于 HTTP 主接缝的测试点,因为其边界用例矩阵很大,通过 HTTP 驱动会让测试冗长难读。
