# 05: 删除 Memo 时清理它的图片

**What to build:** 让删除一条含图的 Memo 时,磁盘上不留下它的截图。

同时锁住一个**刻意的反直觉决定**:仅仅从正文里删掉图片引用**不删除文件**。不做引用计数的理由是一个不对称 —— 引用计数需要解析正文,而剪切一段文字准备粘到别处的中间态引用数为 0,会造成**不可逆**的误删;而留下几个无人引用的文件是可逆且无害的。

这条票单独存在,就是为了用一条明确的行为测试把这个决定钉住,否则后来者(包括 AI agent)很容易顺手「补上」引用计数。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 删除一条含图的 Memo 后,它的图片文件从磁盘消失
- [ ] 仅从正文中删除图片引用并保存后,图片文件**仍然保留**
- [ ] 不引入引用计数机制
- [ ] HTTP 接缝测试覆盖上述两条行为
