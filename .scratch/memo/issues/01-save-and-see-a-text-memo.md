# 01: 记下并看到一条纯文字 Memo

**What to build:** 打通「打开工具 → 输入文字 → 保存 → 看到它出现在列表里」这条最窄的完整路径。

这是本项目的第一条端到端路径,因此应用骨架 —— 后端服务、数据库与迁移、模块划分、前端外壳、开发与构建脚本 —— 随这条路径一并立起,而不是单独作为一个阶段。骨架不是这张票的目的,让第一条 Memo 能被存下来并显示出来才是;骨架只做到支撑这件事所必需的程度。

本票确立的模块结构会被后续四个功能(Evidence、书签、Todo、脚本)照抄,因此模块内部的职责划分要在这里定型。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 打开页面后输入框自动获得焦点,不需要任何点击就能开始输入
- [ ] 输入文字后按 `Ctrl+Enter` 保存
- [ ] 保存后该 Memo 立刻出现在列表顶部,显示正文首行
- [ ] 保存后输入框清空并保持聚焦,可以直接接着记下一条
- [ ] 列表按**创建时间**倒序排列
- [ ] 刷新页面后已保存的 Memo 仍在
- [ ] Memo 没有标题字段;列表中显示的首行由展示层从正文截取
- [ ] 服务只监听回环地址,局域网内其他机器无法访问
- [ ] 数据库文件与图片目录位于同一个父目录下,目录内部只使用相对路径,整个目录可被直接拷贝
- [ ] HTTP 接缝上的测试:创建一条 Memo 后能在列表中读到它,测试使用临时数据目录
- [ ] 模块内部职责划分清晰,后续功能可照抄该结构
