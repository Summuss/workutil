# 02: 选中、删除、撤销红框

**Status:** resolved

**Blocked by:** 01

**What to build:** 在框选模式里点一个框就选中它,按 `Delete` 删掉,按 `Ctrl+Z` 撤销上一步。这一张不做拖动改位置和拉角改大小,理由见 [spec](../spec.md)。

- **选中**:框选模式下,在一个框的线上或框内点一下,不拖动,就选中它。选中的框换一种画法(比如更粗,或者加一圈白色描边),在截图上无论什么底色都要看得出来。一次只选中一个。
  - 几个框叠在一起时,选**最上面**(最后画的)那个。
  - 在图上空白处点一下,不拖动,就取消选中。从框内开始拖,照样是画一个新框,不会变成移动这个框。
- **删除**:有选中的框时,按 `Delete` 或 `Backspace` 删掉它,然后 PUT 整组。
- **撤销**:`Ctrl+Z`(macOS 上是 `Cmd+Z`)撤销**当前这张图**上的上一步,画框或删框都算一步。撤销之后同样 PUT 整组。
  - 撤销的记录只活在这一次打开灯箱期间,并且只管当前这张图。用 `←` `→` 翻到别的图、或者关掉灯箱,记录就清空。跨图撤销要连带翻页,不值得。
  - 没有可撤销的步骤时,按了什么都不发生。
- 保存失败的处理和 01 一样:退回 PUT 之前的那组,并给一句提示。
- 这些按键只在框选模式下生效,不和 `←` `→` / `Esc` 冲突。
- 不在框选模式时,点框什么都不会发生,框只是用来看的。

### 验收

- [x] 画三个框,点中间那个,它看起来是选中的;按 `Delete`,它没了;刷新之后也没了
- [x] `Ctrl+Z`,刚删的框回来了;再按一次 `Ctrl+Z`,最后画的那个框没了
- [x] 两个框叠在一起时,点重叠的部分,选中的是后画的那个
- [x] 选中一个框之后点图上的空白处,不再有框被选中
- [x] 翻到下一张图,`Ctrl+Z` 不会动到上一张
