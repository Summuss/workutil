# 02: Todo 编辑表单的草稿

**Status:** resolved

**Blocked by:** 01

**What to build:** `TodoItem` 的编辑表单接 `useDraft`,**标题和说明作为一份草稿**。

**这条的全部重点是「一起」。** 表单里标题是单行 `input`、说明是多行 `textarea`,照「多行留、单行丢」执行,按下 `Esc` 的结果是说明留着、标题回到已保存的值 —— 下次打开是上半截旧、下半截新,而且没有任何东西说明这两半来自不同时刻。**这比全丢更坏**,所以整张表是一个草稿单位。

- key 用 `draft:todo:<id>`,`saved` 是 `{ title, description }` 的序列化形式(两个字段任一不同都算脏)。
- `Esc`(标题框和说明框两处都有)= 收起表单,草稿留着。
- 「取消」改名「放弃」,`isDirty` 时先问一次。
- 列表里那条 Todo 要看得出**有没保存的修改** —— 和「有说明」那个记号区分得开,别叠成一团。
- 已完成的 Todo 是只读的,不参与草稿。

- [x] 改标题和说明各写几个字,按 `Esc` → 表单收起,列表里这条看得出有未保存的修改
- [x] 刷新页面再打开编辑 → **标题和说明都是刚才那一版**,没有半新半旧
