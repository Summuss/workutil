# 03: 书签(分组 + 组内书签)改为拖拽排序

**What to build:** 用 02 搭好的可复用 sortable 包装,把 `BookmarkGroupSection`(分组自身的排序)和 `BookmarkItem`(组内书签排序)都从按钮改成拖拽。两处都去掉「上/下」按钮、保留「置顶/置底」、加拖拽把手 —— 和 Todo 是同一套模式,不是重新设计一遍。

拖拽范围严格保持不变:分组只能在「所有分组」这一层里排序,书签只能在**同一个分组内**排序,不做跨分组把书签拖到另一个组 —— 那是能力扩展,不在这次范围内。

**Blocked by:** 02

**Status:** resolved

- [x] `BookmarkGroupSection`:去掉分组的「上/下」按钮,保留「置顶/置底」,加拖拽把手,分组间可拖拽排序

- [x] 键盘拖拽可用(复用 02 的 sensor 配置)
