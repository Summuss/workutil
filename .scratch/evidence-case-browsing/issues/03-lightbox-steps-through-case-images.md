# 03: evidence 灯箱 `←` `→` 逐张核对,关掉时停在最后那张

**Status:** ready-for-agent

**Blocked by:** 01, 02

**What to build:** evidence 里打开的灯箱能用 `←` `→` 在**当前用例的图片 Block** 之间切换;关掉时,列表停在最后看的那张。memo 不接这个。

核对一个用例就是逐张看。02 之后灯箱能看清了,但每看一张都要「点开 → 读 → `Esc` → 往下滚 → 再点开」;这一条把它变成「点开第一张 → 一路 `→`」。

**灯箱的状态要从 `BlockCard` 提到 `CaseBlocks`。** 现在每张卡片各持一个 `lightboxOpen`,而切到下一张需要知道整个用例的图片顺序 —— 只有 `CaseBlocks` 知道。卡片只负责报告「我被点了」。

`shared/Lightbox` 加**可选**的 props(例如 `onPrev` / `onNext` / 一个位置说明),不传时行为和 02 之后完全一样 —— memo 就是不传的那一方。

- 顺序 = 当前用例的 Block 顺序里的 image Block,跳过文字和表格;加载失败的图也跳过(卡片上它本来就点不开)。
- 到第一张按 `←`、到最后一张按 `→`:停住,不循环。对应方向的按钮(如果画了)置灰。
- 顶部显示 `3 / 7`,有小标题就跟着显示小标题 —— 核对时要知道自己在看哪一段。
- 切换后滚回顶部(02 的滚动层)。
- `←` `→` 只在灯箱开着时生效,和 `Esc` 一样挂 document 级。
- **关掉时**:如果翻过页,把最后看的那张所在的 Block `scrollIntoView({ block: "nearest" })`。01 之后一张卡片不超过一屏,`nearest` 就等于整张卡片都在视野里。**没翻过就一格不动** —— 和现在一样。
- 灯箱开着的时候 Block 列表被改了(理论上不会,灯箱是模态的)不需要特别处理。

- [ ] 一个用例里有 文字 / 图 A / 表格 / 图 B / 图 C:点 A 开灯箱,按 `→` 依次是 B、C,再按不动;按 `←` 回到 A
- [ ] 顶部显示 `1 / 3` 这样的位置,有小标题的图显示小标题
- [ ] 在一张长图上滚到下面,按 `→`,下一张从顶部开始
- [ ] 从 A 翻到 C 再关:列表停在 C 那张卡片,整张可见
- [ ] 点开 A 不翻就关:列表一格没动
