# 02: 灯箱按宽度铺满、纵向滚动

**Status:** ready-for-agent

**Blocked by:** 无

**What to build:** `shared/Lightbox` 从「整张塞进一屏」改成「按宽度看清」。memo 和 evidence 共用这一个组件,两边一起变。

现在是 `max-h-[90vh] max-w-[90vw] object-contain`:一张 1920×6000 的长截图会被压成一条看不清的窄带,而灯箱存在的意义就是看清。

- 图的宽度 = min(原图宽, 视口宽 − 留白),高度按比例,**不放大超过原图**(memo 那条既有的约束)。
- 比视口高时,**遮罩层自己纵向滚动**,打开时从顶部开始。比视口矮的图照旧上下左右居中 —— 普通截图在大屏上的观感不能变。
- 滚到头不带着后面的页面滚(`overscroll-behavior: contain`)。
- 键盘滚动:`↑` `↓` `Space` `PageUp` `PageDown` 要能直接用。这要求打开时焦点落在滚动的那一层上(`tabIndex={-1}` + 打开时 `focus()`)。
- `Esc` 的监听**仍然挂在 document 级**,不要因为现在有了可聚焦元素就挪到遮罩上(design.md §6 F1 记过原因;焦点被点走后挂在元素上的监听就收不到了)。
- 关闭方式不变:`Esc`、点遮罩、点右上角 ✕。点图本身不关。滚动条区域上的点击不能被当成「点遮罩」关掉。
- 右上角 ✕ 在滚动时要一直看得见(固定在视口上,不跟着图走)。
