# 用例里图多、图长时:看得全、看得清、找得到

## 起因

用例里长截图一多,浏览起来非常费劲。拆下来是三件事:

1. **一张图就占好几屏。** 卡片里的图只有 `max-w-full`,没有高度上限;而页面铺满窗口宽度(design.md §3.4),于是显示高度 = 卡片宽 × 原图高宽比。整页长截图(1:3 以上)自然是好几屏;**笔记本上连普通 16:9 截图也放不进一屏** —— 内容区扣掉导航条、标题行、用例标签栏和底部粘贴框,剩下的可视高度只有 400px 上下。
2. **点开也看不清长图。** 灯箱是 `max-h-[90vh] max-w-[90vw] object-contain`,把整张塞进一屏 —— 长图被压成一条看不清的窄带。「截图能点开看原图」这条需求对长图实际上没兑现。
3. **找某一段、调顺序要滚过所有的图。** 拖一个长图 Block 时,`DragOverlay` 拖着的是整张卡片的副本,几千像素高。

两种用法都真实存在:有时是**核对内容**(导出前通读),有时是**找某一段、调顺序**。一个视图兼顾不了「看清每个字」和「一屏看到全貌」,所以拆成三个面,各管一件事:

| 面 | 管什么 |
| --- | --- |
| 卡片 | **看全**:每张图整张缩进一屏,认得出是哪张、有没有贴错 |
| 灯箱 | **看清**:按宽度铺满、上下滚;evidence 里 `←` `→` 在本用例的截图之间翻 |
| 大纲 | **找、排**:每段收成一行,点一行跳回去,拖一行调顺序 |

## 推翻了什么

fixed-layout 的 Out of Scope 写过「Evidence 图片块改缩略图 —— 交付前的核对场景,整张显示是刻意的」,evidence-memo-panel/02 也写过「不要给 evidence 的图加高度上限」。两句话的前提是「一个用例通常只有几屏」,真实使用里不成立。

**保留的是「整张」,推翻的是「按卡片宽度」。** 卡片上的图仍然完整,不裁剪、不藏任何一部分,只是缩到一屏放得下。这和 memo 的 200px 缩略图不是一回事:那个上限是固定值,为的是列表里一条不吃掉一屏;这个上限跟着可视区域走,为的是一张图一眼看全。

考虑过「截掉下半部分 + 展开」:长图的顶部能保持可读,认画面更快。没选,是因为笔记本上**普通截图也超一屏**,截掉的就是它的底部 —— 核对时底部常常正是要看的那条提示,而「这张图下面还有东西」是一个会被看漏的状态。evidence 的底线是「我看到的就是这个值」:卡片优先看全,看清交给灯箱。

## 定下来的

### 卡片:整张缩进一屏

- 图的最大高度 = block 列表的可视高度 − 卡片自身的头部与内边距,使**一整张卡片**(小标题行 + 图)能同时落在视野里。宽度仍不超过卡片。两个上限同时作用、等比缩,**不放大**(比上限小的图原样显示)。
- 上限跟着窗口大小和 memo 侧栏开合实时变,不是写死的像素。
- 长图因此是窄窄的一条 —— 知情的。读它的路是灯箱。
- **不做「按宽度铺满」的切换。** 大屏上通读时原来能直接读字,现在要点开灯箱;灯箱有 `←` `→`,一张一键,不比滚动慢。真用下来不够再加,那是一个 class 的事。

### 灯箱:按宽度看清(`shared/Lightbox`,memo 共用)

- 图的宽度 = min(原图宽, 视口宽 − 留白),高度按比例;比视口高时**在灯箱里纵向滚动**,从顶部开始。比视口矮的图照旧垂直居中。
- memo 一起受益 —— memo 里的长截图现在同样看不清。
- 滚到头不能带着后面的页面滚。
- 键盘能滚:`↑` `↓` `Space` `PageUp` `PageDown`。

### 灯箱:evidence 里逐张核对

- `←` `→` 在**当前用例的图片 Block** 之间切换:按 Block 顺序,跳过文字和表格,到头停住不循环。顶部显示 `3 / 7` 和这张的小标题。切换后滚回顶部。
- **memo 不接 `←` `→`。** fixed-layout 的「不做看图软件」对 memo 仍然成立;它在 evidence 被推翻,是因为核对本来就是逐张看。
- **关掉时,列表停在最后看的那张。** 用 `←` `→` 翻到别的图再关,列表把那张的 Block 带进视野;没翻过就一格不动。核对时发现了问题,关掉就该站在问题旁边去改(删、改小标题、调顺序)。卡片缩进一屏之后,「带进视野」就是整张卡片都看得见。

### 大纲

- 标题行上一个开关,与 memo 侧栏按钮并排,开着时高亮。
- 每个 Block 收成一行:拖拽把手、`⤒` `⤓`、小标题(能改)、内容摘要、删除。摘要:文字取首行;表格「表格 8 行 × 5 列」;图片一个固定高度的小缩略图。
- **内容编辑不出现在大纲里**(改文字、编辑表格、拆行/合并、转表格/转文字、表头开关)—— 那些要看着内容做。
- 点一行(不是点在按钮或小标题上)→ 回到正常视图,并滚到那一段,顶对齐。
- 开关状态**跨用例保持**(整理一整份 evidence 时会连着切好几个用例),**不记 localStorage**:它是做一件事时进去、做完就出来的工具,第二天打开发现内容全收着、又不记得是自己收的,正是要避免的意外。刷新即回到正常视图。
- 底部粘贴框照常可用,新加的段以一行的样子出现并滚进视野。

## 不做

| 项目 | 说明 |
| --- | --- |
| 卡片上「按宽度铺满」的切换 | 见上。灯箱 + `←` `→` 先顶上,不够再加 |
| 灯箱的缩放、旋转 | 按宽度已经是不放大前提下最大的尺寸 |
| memo 灯箱的 `←` `→` | 见上 |
| 大纲里跨用例移动 Block | 另一个功能 |
| 后端返回图片尺寸 | 能让布局在字节到齐前就稳定,但现有「等 `load` 再滚」的做法够用 |
| 导出 | 一行不动。这次全部是呈现层 |
