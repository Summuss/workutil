# 02: 前端复制按钮与立即重命名

**What to build:** 复制按钮放在用例标签栏下方的工具栏里(`CaseTabs` 里「移到最前 / 最后 / 重命名 / 删除」那一排),挨着「重命名」。复制图标新增到 `shared/icons.tsx`,沿用 feather 描边风格。

请求返回后:切到新用例 → 立刻把它的标签切成 `InlineEdit`,初始值是服务端给的建议名并**全选**,直接打字即可覆盖。回车接受,**`Esc` 也接受** —— 名字已经是合法的,取消编辑不等于取消复制。

自动生成的编号几乎一定不是记录者要的那个(真实编号长 `2~5` 这样),而用例名就是交付出去的 sheet 名 —— 这是「自动命名 + 立即重命名」而不是纯自动或纯弹窗的原因。

复用现有的 `caseEdit` busy 态置灰按钮。复制图多的用例会有明显延迟(逐个拷文件),**不加进度条、不设图片数量上限**。
