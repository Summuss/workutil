# Block 的序号与备注

## 起因

测试的时候边做边记,有两样东西现在没有地方放:

1. **只给自己看的一句话。** 比如「这里的值应该是 3,实际是 5,待确认」「第二次执行的结果」。能写的地方只有小标题,但小标题会导出进 Excel,成为交付物的一部分。现在只能写进小标题,导出前再一个个删掉,或者写到别处。
2. **指称某一段的办法。** 一个用例里十几段时,说「第 7 段那张图」只能靠数。灯箱里翻图时也看不出这张是用例里的第几段 —— 顶部的 `2 / 5` 是「第几张图」,不是「第几段」。

## 定下来的

### 序号:位置,不是数据

- 每个 Block 在**卡片、大纲、灯箱**上显示它在本 Case 里的位置,从 1 开始(`#1`、`#2`……)。文字、图片、表格一起数。
- 序号是**渲染时按位置算出来的**,不存、不进接口、**不导出**。插入、删除、拖动之后,所有序号当场跟着变。
- 灯箱顶部原来的 `2 / 5`(第几张图 / 共几张图)保留,序号加在它后面:`2 / 5 · #7 · 小标题`。两个数回答的是两件事:翻到哪了,这是哪一段。

**和 ADR-0003 不矛盾。** ADR-0003 删掉的是**步骤编号**:记录者填写、存下来、导出进交付物,用来表示 1→2→3 的顺序。删掉它是因为插入一节以后,后面的编号全部错位,得一个个手改。这次的序号不是步骤,也不由人填写,它只是「现在排在第几个」的读数,所以不会错位。它不导出,交付物里仍然没有编号。

### 备注:写给自己的一行字

- 三种 Block 都可以有一条**备注**,可选,单行。
- **不导出。** 导出代码不读这一项;Excel 里看不到任何痕迹。这是它和小标题唯一的区别,也是它存在的理由。
- 交互和小标题一样:点开、改、回车存,`Esc` 放弃,清空就是去掉。**没有草稿**,理由同小标题(CONTEXT.md「草稿」:独立的单行改名,重打一遍的成本接近零)。
- **卡片**:有备注时,标题行下面多一行,显示备注,点它就能改。没有备注时,工具条上有一颗「备注」按钮。这一行用和正文不同的颜色(提醒色),一眼能看出它不是内容,鼠标悬停时说明「不会导出」。
- **灯箱**:图片 Block 有备注时,灯箱底部居中显示它,样式和顶部那条说明一样,用提醒色区分。它不接收鼠标事件,框选模式下照样可以在它下面拖动画框。灯箱里**只看不改**。
- **大纲**:不显示备注。大纲用来找段落、排顺序,一行的位置已经被小标题和摘要占满了。
- 复制用例时备注跟着复制。验收要求是「复制之后新用例与原用例逐段一致」。

### 备注不是什么

| 不是 | 为什么 |
| --- | --- |
| 小标题 | 小标题是交付物的一部分,备注不是 |
| Memo | Memo 是独立的记录,能搜、能置顶;备注离开它的 Block 就不存在(和 ADR-0012 画的是同一条线:共享机制,不共享概念) |
| Todo 的说明 | 那是另一个实体上的另一个概念 |
| Excel 的批注(コメント) | 备注根本不导出;导出成批注是另一个需求 |

## 不做

| 项目 | 说明 |
| --- | --- |
| 多行备注 | 先做单行。用下来不够再改成多行,那时要按 CONTEXT.md 的规则加草稿 |
| 在灯箱里改备注 | 只看。用下来不够再加 |
| 导出备注(作为批注或隐藏列) | 和需求正相反 |
| 备注参与搜索 | Evidence 没有搜索(ADR-0001) |
| 自定义序号、序号导出 | 那就是 ADR-0003 删掉的步骤编号 |

## 领域模型

`CONTEXT.md` 加「备注」一条(02 里做)。Block 那一条补一句:屏幕上的序号是位置,不是 ADR-0003 删掉的步骤编号(01 里做)。
