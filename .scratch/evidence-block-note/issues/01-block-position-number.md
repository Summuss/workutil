# 01: 卡片、大纲、灯箱上显示 Block 的序号

**Status:** resolved

**Blocked by:** 无

**What to build:** 每个 Block 显示它在本 Case 里的位置 `#N`,从 1 开始,三种 kind 一起数。纯前端:序号在渲染时由位置算出,不存、不进接口、不导出。理由见 [spec](../spec.md)。

### 前端

- `BlockCard`、`BlockOutlineRow` 已经拿到 `at`(0 起),显示 `#{at + 1}`。
  - 卡片:标题行最左边,小标题之前。等宽字体、淡色,不抢小标题的视线。
  - 大纲:行的最左边,拖拽把手之前,宽度固定,让几行的序号对齐(两位数也不会把后面挤歪)。
- `shared/Lightbox` 加一个**可选**的 `number` prop,不传就和现在一样(memo 不传)。顶部说明从 `2 / 5 · 小标题` 变成 `2 / 5 · #7 · 小标题`。
- `CaseBlocks` 把灯箱当前那张图在 `blocks` 里的位置 + 1 传进去。
- 拖动排序时,乐观更新的那一刻序号就跟着变,不用等服务器回来。现在 `blocks` 已经是乐观重排的,只要序号从 `at` 算就自然成立。

### 文档

- `CONTEXT.md` 的 Block 一条补一句:屏幕上的序号是位置的读数,不是数据,不导出 —— 不是 ADR-0003 删掉的步骤编号。
- `docs/requirements.md` F5 末尾那段「没有步骤编号」补半句:屏幕上显示的序号只是位置,不进交付物。加一条验收要点。
- `docs/design.md` §6 F5「没有步骤编号」那条补上同样的区分。
- `docs/running.md` 的图片 Block 一节「灯箱顶部说明」改成带序号的样子,加一行拖动后序号跟着变。

### 验收

- [x] 一个用例里有 文字 / 图 / 表格 / 图:卡片上依次是 `#1` `#2` `#3` `#4`
- [x] 把 `#4` 拖到最前,它变成 `#1`,其余顺延;刷新后一致
- [x] 删掉 `#2`,后面的序号往前补,没有空号
- [x] 打开大纲,每行最左是同样的序号,十几行时序号列对齐
- [x] 点 `#4` 的图开灯箱,顶部是 `2 / 2 · #4`(有小标题时后面跟小标题);按 `←` 变成 `1 / 2 · #2`
- [x] memo 的灯箱顶部没有任何序号
- [x] 导出的 Excel 里没有序号
- [x] `pnpm build` / `tsc` 通过;中日文案的 key 对齐测试通过
