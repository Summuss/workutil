# Memo 与 Evidence 是两个独立概念

Memo 和 Evidence 表面上高度相似 —— 都是「文字 + 图片的序列」,都要粘贴截图 —— 所以统一成一个模型是很自然的想法。我们决定**不统一**:两者的生命周期根本不同,Memo 无序、长期沉淀、靠搜索捞回,Evidence 有序、带步骤编号、导出 Excel 后使命即完成。合并会迫使 Memo 背上它不需要的排序与编号,迫使 Evidence 背上它不需要的搜索与归类。

两者共享的是**图片粘贴与存储的技术链路**,不是领域模型。共享机制、不共享概念。

## Consequences

代码里会出现两套结构相似的表和接口。这是刻意的,不是重复 —— 除非某天两者的生命周期真的收敛了,否则不要「顺手」把它们合并掉。
